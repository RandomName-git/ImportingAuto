# 🚗 AutoImport Analytics Service

## ⚠️ Проблема
На текущем рынке импорта автомобилей наблюдается дефицит прозрачности. Покупатели вынуждены переплачивать скрытые комиссии посредникам, а отсутствие четких расчетов приводит к недоверию и отказам от выгодных сделок.


## 💡 Решение
Единый сервис-калькулятор, предоставляющий **актуальный на сегодняшний день** расчет стоимости привоза из Грузии, Китая, Японии и Кореи со всеми юридическими и временными аспектами.

---

## 🛠 Функциональные требования

*   **Roadmap Процесса:** Интерактивная диаграмма с пошаговым описанием этапов импорта для каждой страны.
*   **Верификация данных:** Расчет на основе официальных тарифов (ФТС, ФНС, логистические компании, аукционные площадки).
*   **Умный калькулятор:** Расчет итоговой цены на основе параметров авто.
*   **Льготный фильтр:** Каталог моделей, попадающих под льготный утилизационный сбор.
*   **Currency Engine:** Автоматическое обновление курсов валют (CNY, JPY, KRW, USD, EUR) через **API ЦБ РФ**.
*   **Age Logic:** Автоматическая классификация ставок пошлины по возрасту:
    *   *New* (до 3 лет)
    *   *Fresh* (3–5 лет)
    *   *Old* (5–7 лет)
    *   *Vintage* (свыше 7 лет)

---

## ⚙️ Технические (нефункциональные) требования

*   **Stack:** Java (Minimalistic core).
*   **Stateless:** Сервер не хранит данные клиента; все вычисления производятся в режиме реального времени (**In-Memory**).
*   **Multi-Currency:** Отображение этапов в валюте оригинала (инвойс) с итоговой конвертацией в рубли.
*   **Error Handling:** При недоступности внешних API (ЦБ РФ) пользователь получает уведомление о временной недоступности сервиса.



### Публичные методы

| Метод | Эндпоинт                    | Описание                                   |
| :--- |:----------------------------|:-------------------------------------------|
| `POST` | `/api/calculator/calculate` | Основной расчёт итоговой цены              |
| `GET` | `/api/currency/rates`       | Актуальные курсы валют                     |
| `GET` | `/api/catalog/privileged`   | Список льготных авто (с пагинацией)        |
| `GET` | `/api/calculator/transit`   | Калькулятор доставки по РФ автовозом       |


## 💻 Tech Stack & Architecture
*   **Backend:** Java 17, Spring Boot 3 (Web, Lombok).
*   **Data Processing:**
    *   **Strategy Pattern:** для переключения логики расчета пошлин в зависимости от возраста авто.
    *   **Data Mapping:** парсинг XML-ответов API ЦБ РФ с использованием Jackson XML.
*   **Testing:** JUnit 5, Mockito (Unit-тестирование бизнес-логики и мокирование внешних сервисов).
*   **Frontend:** Clean JavaScript (Fetch API) + CSS3 (Responsive design).
